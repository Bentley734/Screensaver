# Release packaging

Publish only the installable Screensaver mod ZIP as a GitHub release asset.
Do not upload preview ZIPs, modpkg files, checksums or other downloads: extra
assets confuse the in-launcher mod updater. Keep previews in repository docs
and local validation/checksum records outside the release assets.

Preserve the standing workspace authorization to validate, package, publish
the latest release, verify the uploaded ZIP and report its link.
